# M2.GESTIONS — site final

## Mise en ligne sur GitHub Pages

1. Créer un dépôt GitHub, idéalement `m2gestions.github.io`.
2. Importer tous les fichiers de ce dossier à la racine du dépôt.
3. Dans **Settings → Pages**, choisir **Deploy from a branch**, branche `main`, dossier `/ (root)`.
4. Enregistrer puis attendre la publication.

Le site est statique : aucun serveur n'est nécessaire.

## Contact

Le formulaire prépare un e-mail vers `m2.gestions@gmail.com`. Il ne stocke pas les données dans une base de données.
